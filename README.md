# Педагогический симулятор

Объединенный клиент-серверный проект для тренировки принятия педагогических решений.

О проекте
Педагогический симулятор — это интерактивная образовательная среда, построенная на онтологической модели педагогиче>
- Тренировать принятие решений в условиях неопределенности   
- Анализировать сложные ситуации из реальной школьной практики
- Развивать рефлексивность через анализ последствий решений  
- Формировать стратегическое мышление и этическую компетентность

Проект основан на 3 типах педагогических конфликтов, выделенных в онтологической модели:
- Мотивационные кризисы - демотивация, апатия, сопротивление 
- Организационные конфликты - нарушения структуры урока, времени, заданий
- Конфликты взаимодействия - агрессия, игнорирование, публичное унижение

Ключевые особенности:
- Динамические ситуации - развитие сюжета в зависимости от выбора
- Ветвящиеся сценарии - разные пути развития и финалы
- Обратная связь - анализ последствий принятых решений
- Методические комментарии - объяснение педагогических принципов
- Оценка решений - по шкале успешности (успех/частичный успех/провал)
- Метрики влияния - изменение мотивации, доверия, климата в классе
- Долгосрочные последствия - анализ отложенного эффекта решений
- Педагогические принципы - связь решений с теорией



## 🚀 Быстрый старт

### Установка
```bash
# 1. Клонировать репозиторий
git clone https://github.com/panda-sis-ui/teacher-simulator-unified.git
cd teacher-simulator-unified

# 2. Установить все зависимости (клиент, сервер, корневые)
npm run install-all

# 3. Запустить в режиме разработки
npm run dev
```
После успешного запуска:
- React приложение будет доступно по адресу: http://localhost:3000
- PI сервер будет доступен по адресу: http://localhost:5000
- API Endpoints можно тестировать: http://localhost:5000/api/situations

Альтернативный запуск:
```
# Запустить только сервер API
npm run dev:server

# Запустить только клиент (в другом терминале)
npm run dev:client

# Продакшен сборка и запуск
npm run build    # Собрать React приложение
npm start        # Запустить продакшен сервер
```

Функциональные возможности
Для пользователей (педагогов):
- Просмотр случайных ситуаций - новые сценарии при каждом обновлении
- Выбор по категориям - фильтрация по 7 типам конфликтов
- Интерактивное прохождение - принятие решений с последствиями
- Анализ результатов - оценка эффективности решений
- Рефлексия - анализ педагогических принципов

Для администраторов/разработчиков
- Расширяемая база ситуаций - добавление новых сценариев
- Онтологическая модель - структурирование знаний
- API для интеграций - возможность подключения к другим системам
- Генератор ситуаций - создание новых учебных кейсов
